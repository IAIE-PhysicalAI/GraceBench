# GraceBench

Public academic project website for “How GUI Agents Fail: GraceBench for Execution Stability Diagnosis”.

This repository contains the public website, figures, and overview film only.
Raw execution traces, local audit reports, authoring scripts, and historical recordings are not included.

## Hosting

GitHub Pages: in repository Settings → Pages, select “Deploy from a branch”, branch `main`, folder `/ (root)`.
The project URL is https://iaie-physicalai.github.io/GraceBench/.

## Updating

Regenerate this public bundle from the private authoring workspace with `node scripts/prepare-public.mjs`.
Review and push only public website files to this repository.
